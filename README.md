## Big Ten Women's Basketball Analytics Dashboard 

An interactive, full stack static data visualization dashboard built for the Big Ten Women's College Basketball dataset. This project transforms raw ESPN/SportsDataverse box scores into a dynamic, filterable, and highly visual web application.
